# Shared ink textures

Generated by `blender/tex/build_textures.py` (Blender 5.2, headless, fixed seeds). Do not hand-edit; re-run the generator instead:

```
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup -P blender/tex/build_textures.py
```

All alpha textures use **straight (non-premultiplied) alpha**. "White + alpha" means RGB = white and alpha = ink amount, so the game can tint them with any colour (`material.color`, CSS `mask-image`, and so on).

| file | size | colour convention | intended use |
|---|---|---|---|
| `paper.webp` | 1024×1024, opaque, WebP q95 (~100 KB) | warm rice-paper RGB, mean luma 0.92, subtle fibres and grain, tiles seamlessly in x and y | full-screen **multiply** overlay (screen-space tiling) |
| `splat_0.webp` | 512×512 | white + alpha | radial ink splash with spikes and satellite droplets |
| `splat_1.webp` | 512×512 | white + alpha | directional, thrown splatter (flies toward +x; flip or rotate for other directions) |
| `splat_2.webp` | 512×512 | white + alpha | blob with drips running down (+y down in the image) |
| `splat_3.webp` | 512×512 | white + alpha | flicked spray: small blob and a cone of fine droplets toward +x |
| `crater.webp` | 1024×1024 | **real colours** (paper plates, grey washes, ink cracks) + alpha | top-down shattered-ground decal for heavy impacts. Plates and pit are opaque; cracks and rubble outside the ring are alpha. Painted round (true top-down), so scale the decal quad about **3× along z** to match the floor's grazing-angle stretch |
| `cracks.webp` | 1024×1024 | white + alpha (tint with ink `#1b1a17`) | radial ground cracks for lighter hits. Same z-stretch advice as the crater |
| `speedlines.webp` | 1024×1024 | white + alpha | manga radial speed lines, dense at the edges, transparent centre (r < ~20 %). Overlay on screen; stretch to the screen aspect |
| `brush_stroke.webp` | 1024×160 | white + alpha | one horizontal dry-brush stroke (heavy press on the left, dry split tail on the right) for health and loading bars. Use as a CSS `mask-image` over a coloured fill, or tint in WebGL |
| `enso.webp` | 512×512 | white + alpha | ensō brush circle (loading spinner, menu emblem, KO frame) |
| `mist.webp` | 1024×256 | white + alpha, **tiles horizontally** | soft horizontal mist band. Scroll its UV in x for drifting fog; fade the quad ends with vertex alpha if it is not repeated |

Other files in this folder (for example `palm.webp`) are not produced by this generator.
