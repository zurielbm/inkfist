# Blender asset pipeline

All INKFIST art is generated by these scripts (Blender 5.2, headless).

```
./blender/run.sh build_chars.py -- mujin --export          # build + bake + export game/assets-src/chars/mujin.glb/.json
cd game && npm run optimize                                 # meshopt-compress into game/public/assets/chars/
./blender/run.sh build_chars.py -- mujin --preview rest     # contact sheet -> .scratch/previews/ (add --nobake to skip textures)
```

`game/viewer.html` (dev server only) shows one fighter through the real in-game ink pipeline:
`/viewer.html?char=hyeongong&clip=idle&t=0.3&play=0&cam=full|bust|face|handL|handR&yaw=20&expr=shout`
(`hide=hair` hides a mesh group, `dbg=uv` paints texture coordinates, `ui=0` hides the toolbar).

## Base mesh

Bodies start from the CC0 Blender Studio **Human Base Meshes** (v1.4.1, realistic male/female, one shared topology).
The extracted shapes are committed as `base/hbm_base.npz`; re-extract only when changing the source:

```
./tools/fetch-basemesh.sh                                   # downloads the bundle into blender/base/.cache/
./blender/run.sh base/extract_base.py
```

## Character pipeline (`rig/`)

Body and rig
- `base.py` — `Topo` (adjacency, boundary loops, geodesics, smoothing) over the base mesh; `load_base`, `base_topo(shape, blend)`.
- `anatomy.py` — joints as anatomical landmarks (affine combinations of edge points), so they follow any reshaped body.
- `body.py` — `Body(sex, blend)`: proportions (`stretch_z`, `scale_region`, `inflate`, `fit_height`…), eye/mouth rings, `Regions` masks.
- `skeleton.py` — 20 shared bones + 30 finger bones + forearm twist bones; `build_armature`, `make_chain`.
- `skin.py` — bone-heat weights, smoothing, 4-influence limit, `SurfaceSampler` weight transfer, chain weights.
- `face.py` — eyeballs fitted to the sockets, lashes, brows, morph targets (`blink, glare, pain, shout, smirk`).

Costume and hair
- `part.py` — `Part`: one mesh piece with UVs, paint, weights, attributes, outline width; `merge_parts`.
- `garment.py` — body-derived shells (membrane relax, layered clearance), skirts/rings/bands/tubes, `solidify` with lining.
- `outfit.py` — dressing proxy, skirt extrusion with slits, chained panels, sleeves, shoes.
- `hair.py` — scalp shell plus guide-curve clumps (`curve_lock`) that can hang on spring chains.

Surfacing, assembly, motion
- `paint.py` — shelf-packed UV atlas, procedural recipes baked to a 2048 albedo and a 1024 **ink map**
  (R light bias from AO, G sheen, B inner lines). Spring-chain parts never cast baked occlusion.
- `assemble.py` / `charkit.py` — weight resolution, mesh objects, custom normals, `_OUTLINE` attribute (smoothed normal +
  halved width), collider capsules for the game's chain physics.
- `pose.py` — FK spine, analytic 2-bone IK, finger grips, clip baking; `set_legacy` remaps clips authored for the old skeleton.
- `chars/<id>.py` — body shape, chains, garments, trims, hair, palette; `build()` returns the rig and meshes.
- `anims/common.py`, `anims/<id>.py` — stance, generic and signature clips, `GRIP_*` hand shapes, preview poses.
- `preview.py` — workbench contact sheets. `parts.py` / `core.py` — legacy primitives (still used by `render_art.py`).

Character space for poses: `(side, fwd, up)`; side>0 = character's LEFT; the in-game camera sees the character's RIGHT side.
Secondary chains (hair/cloth/scarf/sleeves/beads) are NOT keyed: the game simulates them with springs and body capsules
using the `chains` and `colliders` metadata.
