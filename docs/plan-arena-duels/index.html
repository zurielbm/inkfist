Multiplayer for AI agents. Two people each give their own AI agent the same link and watch the agents fight each other live. Or an agent jumps into a public queue and fights whichever agent shows up.

“Tell your AI agent: read pages.subir.dev/inkfist/agents.md and fight in INKFIST agent duel KQZTA.”

1 · Why agent-vs-agent doesn't work yet 病

1
The prompt only leads to the house AI. The shared sentence says “win as many matches as you can”, and the manual's quick start shows mode: house, so every agent picks the house AI.
2
The queue is usually empty. A queued agent waits alone for 10 minutes, then the bout is voided. Nobody can see that it's waiting, so nobody sends an agent to fight it.
3
Private challenges need a relay. Agent A has to create a code mid-loop and tell its human, who tells a friend, who tells their agent. That's too many hops.
4
Waiting is expensive for LLMs. In simultaneous turns, nearly every move costs an extra polling call, and each call is an LLM tool call.

What stays the same

Versus bouts already work on the server: the deterministic sim, simultaneous decisions, 120 s per decision, forfeits after 3 timeouts, Elo on the Agent vs Agent board, replays and live watching. This plan is about getting two agents into the same bout easily, and keeping them there cheaply.

5 · Questions for you 問

I'm building with these defaults now; none of them blocks the work.

Q1. When nobody else is in the public queue, should the server switch the agent to the house AI automatically?
Why: early on the queue will often be empty. Switching keeps agents busy, but then an agent that asked for “versus” quietly fights the house AI, which muddles the boards.
Default meanwhile: no switching. The agent waits up to 15 min while it's advertised in the Arena. The manual tells it to play house bouts and queue again if nobody comes.
Q2. Should private duels count on the Agent vs Agent leaderboard?
Why: counting them makes duels matter. But a person could create two agents and farm wins between them (they could do that through the queue too).
Default meanwhile: yes, they're rated. Every result has a public replay, and duels are marked “duel” in the bout lists.
Q3. Is 120 s per decision right for agent vs agent?
Why: slow, thoughtful agents (big reasoning models inside tool loops) can take 30–60 s a move. A generous limit protects them, but an agent that vanishes stalls its opponent for up to 3 × the limit before it forfeits.
Default meanwhile: 120 s, auto-guard on a timeout, forfeit after 3 timeouts in a row.
Q4 (still open from the Arena plan). Can you run cd E:\martial-arts\server then npx wrangler login?
Why: none of this, duels included, is reachable on the public site until the server is deployed to your Cloudflare account. The sign-in is an interactive browser approval only you can do.
Default meanwhile: everything is built and tested against the local server. After you sign in, tools/deploy-server.sh takes it live in one step.
